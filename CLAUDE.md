## Project Overview

Luxury real estate website for Gloria Rossi, a realtor in Viera, Florida. This is a learning project where the developer is building web development skills while creating a production-ready site.

## Tech Stack

- **HTML/CSS/JavaScript** - Chosen to learn fundamentals before frameworks
- **Hosting**: GitHub Pages (deployed from main branch)
- No build tools or frameworks - static HTML site

## Project Structure

```
index.html              # Home page (featured properties loaded from data/featured.json)
about.html              # About Gloria - bio, credentials, philosophy
contact.html            # Contact form (Formspree) + contact info
properties.html         # Property search & listing page (loads data/listings.json)
property.html           # Individual property detail (query param: ?id=<ListingKey>)
css/styles.css          # All styling (midnight #0d1b2a + gold #c5a028 color scheme)
data/listings.json      # All active MLS listings (auto-generated by GitHub Action)
data/featured.json      # Featured subset for homepage (auto-generated)
scripts/fetch-listings.js   # Node.js script to fetch from Spark API
.github/workflows/fetch-mls.yml  # Scheduled GitHub Action (every 4h)
pictures/               # Images (Gloria's headshot)
docs/planning/          # Planning documentation
```

## Development

- Open `index.html` in browser to preview locally
- Push to `main` branch to auto-deploy to GitHub Pages
